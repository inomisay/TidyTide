The problem

Select a bunch of files in Windows and rename them all at once, and you get photo (1), photo (2), photo (3)… If you only wanted 1, 2, 3, you're stuck fixing every name by hand. Tidy Tide does it for you.

What it does

It does one job and it's careful about it.

Number becomes the name

photo (12).jpg becomes 12.jpg, and (7).png becomes 7.png.

Preview first

You see every change before it happens. Nothing is renamed until you press Rename.

Undo

Changed your mind? Undo puts the last rename back the way it was.

Sorts properly

Can add zeros in front (01, 02 … 10) so every app lists the files in the right order.

Never overwrites

Skips files with no number in brackets, numbers used twice, and names that are already taken.

Right-click Send to

Right-click files or a folder in File Explorer and choose Send to → Tidy Tide.

Install

Takes about a minute. Works on Windows 10 and 11 with the PowerShell that's already built in. You don't need to install anything else.

  1. Download the ZIP and unzip it.
  2. Double-click Install Tidy Tide.bat.
  3. Read the licence in the window that opens, then click Install.
  4. Open Tidy Tide from the desktop icon or the Start menu.

If Windows shows “Windows protected your PC”, click More info → Run anyway. Windows shows this for scripts downloaded from the internet. On Windows 11, Send to is under Show more options. To remove Tidy Tide, run Uninstall Tidy Tide.bat.
