What it does

One small job, done carefully

Select a bunch of files in Windows and rename them all at once, and you get photo (1), photo (2), photo (3)… Tidy Tide turns them into plain 1, 2, 3.

The number becomes the name

photo (12).jpg becomes 12.jpg, and (7).png becomes 7.png.

Preview first

You see every new name before anything changes. Nothing is renamed until you say so.

Easy undo

Changed your mind? One click puts the last rename back the way it was.

Sorts the right way

Optional zeros in front (01, 02 … 10) so every app lists files in order.

Never overwrites

Files with no number, duplicate numbers or names already in use are left alone.

Right-click → Send to

Right-click files or a folder in File Explorer and choose Send to → Tidy Tide.

Install

Ready in about a minute

It uses the PowerShell that's already built into Windows, so there's nothing else to install.

DownloadGet the ZIP and unzip it anywhere.
Run the installerDouble-click Install Tidy Tide.bat.
Read the licenceA window shows it. Click Install.
Start tidyingOpen it from the desktop or the Start menu.
If Windows shows “Windows protected your PC”, click More info → Run anyway. Windows shows this for any script downloaded from the internet. On Windows 11, Send to is under Show more options. To remove the app, run Uninstall Tidy Tide.bat.
